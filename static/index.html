HS code lookup, traced to the rulings that decide it

Describe your goods. You get a 6-digit HS subheading with the published CBP rulings that support it — or an explicit refusal to answer when they don't.

Free. No account. The more specific the description, the better the result.

Why this refuses to answer sometimes

An HS code on a customs entry is a legal declaration. Filing the wrong one is a false statement under 19 U.S.C. §1592, and the penalty follows the importer of record, not the tool that suggested it. Tools that always return a code are optimising for looking useful. This one withholds an answer whenever the retrieved rulings don't support it, and tells you that is what happened.

Where the answers come from

U.S. Customs and Border Protection publishes its classification rulings through CROSS: decades of decisions about specific goods, each naming the subheading CBP assigned and why. Your description is matched against that corpus, and every ruling used is linked so you can read the reasoning yourself rather than take a model's word for it.

What this is not

This is not customs advice, and it is not a binding ruling. Only CBP can issue one, and you can request it free of charge through the same system these answers are drawn from. For a shipment that matters, have a licensed customs broker confirm the classification.
